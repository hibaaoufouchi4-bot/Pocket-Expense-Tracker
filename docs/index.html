Group project · Python + pytest

Pocket Expense Tracker

A compact command-line project for recording transactions, checking monthly budgets, and understanding where expenses go.

What it does

Record

Add income or expenses with a category, date, and optional note. Invalid amounts and dates are rejected.

Budget

Compare a category's monthly expenses with a spending limit and see the remaining amount.

Summarize

See monthly income, expenses, balance, and spending grouped by category.

Run it

Install Python 3.12+, then run python -m expense_tracker. Install the test dependency with python -m pip install -r requirements.txt and run checks with python -m pytest -q.

Transactions stay in memory and clear when the program exits.
