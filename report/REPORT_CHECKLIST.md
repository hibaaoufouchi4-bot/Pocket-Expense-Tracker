# Group report completion checklist

Use the supplied assignment report template to prepare the final PDF after the GitHub activities are complete. Record evidence as it happens; do not claim these actions until you have verified them in GitHub.

- [ ] Group size, chosen theme, names, IDs, course/section, usernames, repository URL, live Pages URL.
- [ ] Feature ownership; branch names; at least two meaningful commits per member.
- [ ] Each feature PR URL and reviewer; meaningful line comments; one Request changes cycle with correction pushed to the same branch.
- [ ] The two conflicting README edits, the merge conflict, the final resolution, and the conflict PR review.
- [ ] Local pytest output and summary of normal, boundary, and invalid-input cases.
- [ ] One failed Actions run, cause, fix, and later successful run.
- [ ] Main ruleset showing PR approval, required passing test status, no force pushes/deletions, and no bypass for normal work.
- [ ] GitHub Pages source setting, final page-change PR, and verification that the live page updated.
- [ ] Contribution summary by member and one honest AI-use paragraph.
- [ ] Sources and a 3-4 sentence reflection.
- [ ] About 8-10 screenshots that prove important states.
- [ ] Export one group report PDF and commit it in the repository.
